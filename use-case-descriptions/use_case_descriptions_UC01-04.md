## UC-01 회원 가입

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 로그인, 회원 가입 선택 화면을 출력한다. |
| 3. 비회원이 회원 가입 항목을 선택한다. | 4. 회원 가입 화면을 출력한다. |
| 5. 비회원이 ID, 비밀번호, 이름, 전화번호, 이메일을 입력한다. |6. None |
| 7. 비회원이 입력 내용을 확인하고 가입 버튼을 선택한다. | 8. 로그인 화면을 출력한다. |

## UC-02 로그인

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 로그인/회원가입 선택 화면을 출력한다. |
| 3. 회원/관리자가 로그인 버튼을 선택한다. | 4. 로그인 화면을 출력한다. |
| 5. 회원/관리자가 ID와 비밀번호를 입력한다. 관리자는 ID `admin`, 비밀번호 `admin`을 입력한다. | 6. None |
| 7. 회원/관리자가 로그인 버튼을 선택한다. | 8. 회원이면 회원 메인 화면을 출력하고, 관리자이면 관리자 메인 화면을 출력한다. |

## UC-03 로그아웃

| Actor Action | System Response |
| --- | --- |
| 1. 회원/관리자가 현재 화면에서 로그아웃 버튼을 선택한다. | 2. 로그인 상태를 해제하고 로그인 화면으로 이동한다. |

---

## UC-04 회원 탈퇴

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 회원 탈퇴 버튼을 선택한다. | 2. 회원 탈퇴 확인 화면을 보여준다. |
| 3. None | 4. 탈퇴 시 모든 이용 권한과 데이터가 삭제된다는 안내 문구를 보여준다. |
| 5. 회원이 안내 내용을 확인한 뒤 탈퇴 확인 버튼을 선택한다. | 6. 회원 탈퇴 완료 메시지를 보여준다. |
| 7. None | 8. 로그아웃 상태로 전환하고 로그인 화면 또는 메인 화면으로 이동한다. |
