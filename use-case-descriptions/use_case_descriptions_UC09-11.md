## UC-09 설문 검색

| 항목 | 내용 |
|------|------|
| **Use Case ID** | UC-09 |
| **Use Case Name** | 설문 검색 |
| **Actor** | 회원 |
| **Preconditions** | 회원은 로그인한 상태이다. |
| **Postconditions** | 검색한 설문 리스트 조회 화면(UC-10)으로 이동한다. |
| **Trigger** | 회원이 회원 홈 화면에서 설문 검색 버튼을 선택한다. |

### Steps

| Step | Actor | Action / System Response |
|------|-------|--------------------------|
| 1 | 회원 | 회원 홈 화면에서 설문 검색 버튼을 선택한다. |
| 2 | 시스템 | 설문 검색 화면을 보여준다. |
| 3 | 회원 | 상태(진행 중 / 진행 예정 / 종료됨) 중 하나를 선택한다. |
| 4 | 회원 | 키워드를 입력한다. |
| 5 | 회원 | 검색 버튼을 선택한다. |
| 6 | 시스템 | 상태와 키워드가 모두 입력되었는지 확인한다. |
| 7 | 시스템 | 검색한 설문 리스트 조회 화면(UC-10)으로 이동한다. |

### Alternative Flows

| 구분 | 내용 |
|------|------|
| A1 | 회원이 취소 버튼을 선택하면 시스템은 검색을 진행하지 않고 회원 홈 화면으로 돌아간다. |

### Exception Flows

| 구분 | 내용 |
|------|------|
| E1 | 상태를 선택하지 않은 경우 시스템은 상태 선택 요청 메시지를 보여준다. |
| E2 | 키워드를 입력하지 않은 경우 시스템은 키워드 입력 요청 메시지를 보여준다. |

## UC-10 검색한 설문 리스트 조회

| 항목 | 내용 |
|------|------|
| **Use Case ID** | UC-10 |
| **Use Case Name** | 검색한 설문 리스트 조회 |
| **Actor** | 회원 |
| **Preconditions** | 회원은 로그인한 상태이며, 설문 검색(UC-09)을 완료한 상태이다. |
| **Postconditions** | 조건에 맞는 설문 리스트가 화면에 출력된다. |
| **Trigger** | 회원이 설문 검색(UC-09)에서 검색 버튼을 선택한다. |

### Steps

| Step | Actor | Action / System Response |
|------|-------|--------------------------|
| 1 | 시스템 | 검색 조건에 맞는 설문 리스트를 화면에 출력한다. |
| 2 | 회원 | 검색 결과 리스트를 확인한다. |

### Alternative Flows

| 구분 | 내용 |
|------|------|
| A1 | 회원이 취소 버튼을 선택하면 시스템은 설문 검색 화면(UC-09)으로 돌아간다. |

### Exception Flows

| 구분 | 내용 |
|------|------|
| E1 | 검색 결과가 없는 경우 시스템은 결과 없음 메시지를 화면에 표시한다. |

## UC-11 설문 상세정보 조회

| 항목 | 내용 |
|------|------|
| **Use Case ID** | UC-11 |
| **Use Case Name** | 설문 상세정보 조회 |
| **Actor** | 회원 |
| **Preconditions** | 회원은 로그인한 상태이며, 검색한 설문 리스트 조회(UC-10)에서 특정 설문을 선택한 상태이다. |
| **Postconditions** | 회원은 선택한 설문의 상세 정보를 새로운 화면에서 확인할 수 있다. |
| **Trigger** | 회원이 검색한 설문 리스트 조회 화면(UC-10)에서 특정 설문의 제목을 선택한다. |

### Steps

| Step | Actor | Action / System Response |
|------|-------|--------------------------|
| 1 | 회원 | 검색한 설문 리스트 조회 화면에서 특정 설문의 제목을 선택한다. |
| 2 | 시스템 | 선택한 설문의 상세 정보 화면을 새로운 화면으로 보여준다. |
| 3 | 시스템 | 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 출력한다. |
| 4 | 회원 | 설문 상세 정보를 확인한다. |

### Alternative Flows

| 구분 | 내용 |
|------|------|
| A1 | 회원이 취소 버튼을 선택하면 시스템은 검색한 설문 리스트 조회 화면(UC-10)으로 돌아간다. |

### Exception Flows

없음
