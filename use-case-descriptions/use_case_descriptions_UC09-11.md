## UC-09 설문 검색

| **Actor Action**                                                             | **System Response**                                  |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1. None                                                                      | 2. 설문 검색 화면을 보여준다.                        |
| 3. 상태(진행 중 / 진행 예정 / 종료됨) 중 하나를 선택한 후 키워드를 입력한다. | 4. 검색한 설문 리스트 조회 화면(UC-10)으로 이동한다. |

---

## UC-10 검색한 설문 리스트 조회

| **Actor Action**                                     | **System Response**                                |
| ---------------------------------------------------- | -------------------------------------------------- |
| 1. None                                              | 2. 검색 조건에 맞는 설문 리스트를 화면에 출력한다. |
| 3. 검색 결과 리스트를 확인하고 특정 설문을 선택한다. | 4. 해당 설문의 상세 정보 화면(UC-11)으로 이동한다. |

---

## UC-11 설문 상세정보 조회

| **Actor Action**                              | **System Response**                                                                                                                                                         |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. None                                       | 2. 선택한 설문의 제목, 설명, 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 새로운 화면으로 보여준다. 이때 설문이 진행 중이 아닌 경우, 응답하기 버튼이 비활성화되어 있다 |
| 3. 설문 상세 정보를 확인한다.                 | 4. None                                                                                                                                                                     |
| 5. 응답을 원할 경우 응답하기 버튼을 클릭한다. | 6. 해당 설문의 응답 화면(UC-12)으로 이동한다.                                                                                                                               |
