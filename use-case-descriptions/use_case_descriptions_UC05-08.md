## UC-05 설문 등록

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 설문 등록 화면을 보여준다. |
| 3. 관리자가 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 입력한다. | 4. None |
| 5. 등록 버튼을 누른다. | 6. 관리자 메인 화면으로 돌아간다. |

## UC-06 설문 리스트 조회 $\cdot$ UC-07 설문 상세 조회

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 설문 리스트 화면을 보여준다. |
| 3. 상세 보기할 제목을 클릭한다. | 4. 해당 설문의 상세 내용을 팝업 창으로 보여준다.  |

## UC-08 설문 삭제

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 설문 리스트 화면을 보여준다. |
| 3. 삭제하고자 하는 설문의 체크 박스를 클릭한다.| 4. None|
| 5. 삭제 버튼을 누른다.| 6. 선택된 설문이 제거된 설문 리스트 화면을 보여준다. |
