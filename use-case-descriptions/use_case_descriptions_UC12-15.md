## UC-12 설문 응답

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 설문 상세 정보 화면에서 ‘응답하기’ 버튼을 누른다. | 2. 응답 화면으로 이동한다. |
| 3. 회원이 각 설문 문항에 대해 답변을 선택한다. |  |
| 4. 회원이 ‘응답 제출’ 버튼을 누른다. | 5. 응답 내용을 저장하고 제출 완료 처리한다. |
| Extensions |  |
| 설문이 진행 중이 아닌 경우, ‘응답하기’ 버튼이 비활성화되어 응답 화면으로 이동할 수 없다. |  |

## UC-13 응답한 설문 조회

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 응답한 설문 조회 화면으로 이동한다. | 2. 해당 회원이 응답한 모든 설문 목록을 불러온다. |
|  | 3. 응답한 각 설문에 대해 설문 제목, 응답 내용, 응답 일시를 한 화면에 출력한다. |

## UC-14 응답 수정

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 응답한 설문 조회 화면에서 수정할 설문의 ‘수정’ 버튼을 누른다. | 2. 설문 수정 화면으로 이동하며, 가장 최근에 수정한 날짜를 함께 출력한다. |
| 3. 회원이 응답 항목을 수정한다. |  |
| 4. 회원이 ‘수정 완료’ 버튼을 누른다. | 5. 수정된 응답 내용을 저장하고, 수정한 날짜를 업데이트한다. |
| Extensions |  |
| 설문이 종료된 경우, 수정 버튼이 비활성화되어 응답을 수정할 수 없다. |  |

## UC-15 응답 취소

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 설문 수정 화면에서 ‘응답 취소’ 버튼을 누른다. | 2. 해당 설문에 대한 응답 데이터를 삭제한다. |
| Extensions |  |
| 설문이 종료된 경우, 응답 취소 버튼이 비활성화되어 취소할 수 없다. |  |
