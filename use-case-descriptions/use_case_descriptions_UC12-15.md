## UC-12 설문 응답

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 설문 응답 화면을 보여준다. |
| 3. 회원이 각 설문 문항에 대해 답변을 선택한다. | 4. None |
| 5. 회원이 ‘응답 제출’ 버튼을 누른다. | 6. 설문 상세 정보 화면으로 돌아간다. |

## UC-13 응답한 설문 조회

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 회원이 응답한 모든 설문 정보를 보여준다. (각 응답한 설문에 대해 설문 제목, 응답 내용, 응답 일시 등이 출력된다.) 설문이 진행 중인 경우, 설문 수정 버튼이 활성화되어 있다. |

## UC-14 응답 수정

| Actor Action | System Response |
| --- | --- |
| 1. None | 2. 설문 수정 화면을 보여준다. 가장 최근에 수정한 날짜와 자신이 제출한 응답이 출력되어 있다. 설문이 진행 중인 경우, 응답 취소 버튼이 활성화되어 있다.|
| 3. 회원이 응답 항목을 수정한다. | 4. None |
| 5. 회원이 수정 완료 버튼을 누른다. | 6. 응답 목록 화면으로 돌아간다. |

## UC-15 응답 취소

| Actor Action | System Response |
| --- | --- |
| 1. 회원이 설문 수정 화면에서 응답 취소 버튼을 누른다. | 2. 취소 확인 여부를 묻는 메시지를 출력한다. |
| 3. 회원이 확인 버튼을 누른다. | 4. 응답 목록 화면으로 돌아간다. 취소한 응답은 목록에서 빠진다. |
