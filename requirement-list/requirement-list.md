| No. | Requirement | Use Case(s) |
| --- | --- | --- |
| 1 | 회원 가입 시 ID, 비밀번호, 이름, 전화번호, 이메일을 필수로 입력해야 한다. | 회원 가입 |
| 2 | 탈퇴 시 해당 회원의 모든 이용 권한과 데이터가 삭제된다. | 회원 탈퇴 |
| 3 | 회원과 관리자는 ID와 비밀번호를 입력하여 로그인할 수 있다. 관리자는 주어진 ID(admin)와 비밀번호(admin)로 로그인한다. | 로그인 |
| 4 | 로그인한 회원과 관리자는 메인 화면의 로그아웃 버튼을 통해 시스템 이용을 종료할 수 있다. | 로그아웃 |
| 5 | 설문 등록 시 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 입력해야 한다. | 설문 등록 |
| 6 | 관리자는 등록된 모든 설문의 리스트를 조회할 수 있다. | 설문 리스트 조회 |
| 7 | 관리자는 설문 리스트에서 특정 설문을 선택하여 상세 내용을 팝업 창으로 볼 수 있다.  | 설문 상세 조회 |
| 8 | 관리자는 설문 리스트에서 특정 설문 항목을 선택하여 삭제할 수 있다.  | 설문 삭제 |
| 9 | 회원은 검색 전 현재 진행 중인 설문, 향후 진행 예정인 설문, 종료된 설문 중 하나를 선택한 후, 키워드를 입력하여 조건에 맞는 설문을 검색할 수 있다. | 설문 검색 |
| 10 | 검색 조건에 맞는 설문 리스트가 출력된다. | 검색한 설문 리스트 조회 |
| 11 | 회원은 검색된 설문 리스트에서 특정 설문을 선택하여 새로운 화면에서 상세 정보를 조회할 수 있다. 설문 상세 정보 화면에는 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각이 표시된다. | 설문 상세 정보 조회 |
| 12 | 현재 진행 중인 설문의 경우 응답 버튼이 활성화된다. 회원은 응답 버튼을 눌러 응답 화면으로 이동하여 설문에 응답하고, 응답을 제출하는 버튼을 눌러 응답 완료한다. | 설문 응답 |
| 13 | 회원은 자신이 응답한 모든 설문 정보(설문 제목, 응답 내용, 응답 일시)를 조회할 수 있다. | 응답한 설문 조회 |
| 14 | 회원은 현재 진행 중인 설문에 한해 자신이 제출한 응답을 수정할 수 있다. 설문 수정 화면에는 가장 최근에 수정한 날짜가 표시되며, 수정 버튼을 눌러 완료한다. 설문이 종료된 경우에는 응답 내용을 수정할 수 없다. | 응답 수정 |
| 15 | 회원은 현재 진행 중인 설문에 한해 자신의 응답을 취소할 수 있다. 설문이 종료된 경우에는 응답 내용을 취소할 수 없다. | 응답 취소 |
| 16 | 관리자는 통계 조회 시 최근 1주일, 1개월, 1년 중 하나의 검색 단위를 선택할 수 있다. 선택한 기간 동안의 전체 설문 수, 종료된 설문 수, 총 응답 수가 출력된다.  | 설문 응답 통계 조회 |
